## 🚀 How to Run Locally

### Option 1: Using the Included Python Server
Run the local server script:
```bash
python serve.py
```
Or to automatically launch in your default web browser:
```bash
python serve.py --open
```
Navigate to:
```
http://localhost:8080
```

### Option 2: Direct Browser Launch
Simply double-click or open `index.html` directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Apple Safari. No external build steps or Node.js dependencies required.

## 🎨 Design System & Technologies
- **Typography**: Google Fonts (*Plus Jakarta Sans* for clean modernist typography, *JetBrains Mono* for cryptographic data & code citations, *Merriweather* for simulated official legal documents).
- **Styling**: Tailwind CSS + Custom CSS (`styles.css`) for obsidian glassmorphism, radial glow meshes, customized range sliders, and luminous border transitions.
- **Interactions**: Vanilla JavaScript (`app.js`) with zero third-party dependencies, featuring reactive calculations, streaming text generators, dynamic DOM coordinate targeting, and IntersectionObserver scroll reveals.
